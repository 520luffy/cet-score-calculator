## ✨ 核心特性

- 🎯 **官方考纲分值精准校对**：严格依照全国大学英语四、六级考试大纲赋分权重（总分 710 分，写作 15%、听力 35%、阅读 35%、翻译 15%），修正了题数与满分 710 的严格等价对应关系。
- 🔄 **双模式自由切换**：支持 **CET-4（英语四级）** 与 **CET-6（英语六级）** 一键无缝切换，题型与分值自动适配。
- 🎨 **现代毛玻璃极简美学 (Glassmorphism)**：基于 Tailwind CSS 与精细微质感光晕设计，配合流畅的实时交互与动画效果。
- 📊 **主观题官方五档快捷评定**：写作与翻译不仅支持滑块自由拖动，还提供官方 14 分档（优秀）、11 分档（良好）、8 分档（及格）、5 分档（薄弱）的单键快速选定与评分标准参考。
- 💡 **AI 智能考情诊断与突破建议**：根据各题型得分占比，自动生成短板诊断与备考策略（如重点提醒仔细阅读与听力篇章 14.2 分关键分水岭）。
- ⚡ **快捷模拟战术预设**：内置“425 分及格线战略（战术放弃选词填空）”、“550+ 保研高分优秀档”、“一键满分”与“一键重置”。
- 🖼️ **高保真成绩单海报导出**：支持一键生成高清图片成绩单（PNG），方便分享至社交平台打卡；同时支持一键复制结构化文本成绩单。
- 🌙 **自适应深色模式 (Dark Mode)**：支持浅色/深色主题一键切换与系统级偏好自适应，夜间自习刷题不伤眼。
- 🔄 **即测即算 & 刷新即清零**：默认保持纯净零分初始状态，刷新页面即可一键彻底清零重测，方便随时开展全新模拟。
- 🚀 **零依赖与开箱即用**：纯静态现代化单页面应用，无需繁琐的 Node 构建环境，双击 `index.html` 即可在任意浏览器飞速运行。

## 🧮 官方常模算分原理与公式说明

全国大学英语四、六级考试实行**常模参照赋分**机制，官方报道分公式为：

$$TotSco = \left( \frac{X - \text{Mean}}{\text{SD}} \right) \times 70 + 500$$

- **$TotSco$**：最终成绩单上显示的报道总分（满分 710 分）；
- **$X$**：考生的卷面各部分原始等价加权总分；
- **$\text{Mean}$**：全国常模样本群体的平均分（通常设定为 500 分基准）；
- **$\text{SD}$**：常模样本群体的标准差（70 为尺度扩展因子）。

本计算器采用的大纲加权等价模型在全国考情平均正态分布下，能提供 **&plusmn;5~15 分高精度预测**，是考前摸底规划与考后估分最受认可的实用模型。

## 🚀 本地运行与一键部署

### 方式一：本地极速运行（零配置）

无需安装 Node.js、npm 或任何依赖，只需下载或克隆本仓库：

```bash
# 克隆仓库
git clone https://github.com/your-username/cet-score-calculator.git

# 进入目录
cd cet-score-calculator
```

直接使用任何现代浏览器双击打开 `index.html` 即可畅快使用！

---

### 方式二：部署到 GitHub Pages（一键免费上线）

本项目内置了自动化 GitHub Actions 工作流：

1. 在 GitHub 上点击 **New repository** 创建一个公开仓库。
2. 将本地代码推送到远程仓库：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of cet score calculator"
   git branch -M main
   git remote add origin https://github.com/your-username/your-repo.git
   git push -u origin main
   ```
3. 在 GitHub 仓库设置中：进入 **Settings** &rarr; **Pages** &rarr; **Build and deployment** 下将 **Source** 选择为 **GitHub Actions**。
4. 推送代码后工作流将自动部署，几秒钟后即可获得专属在线网站地址：
   `https://<your-username>.github.io/<your-repo>/`
